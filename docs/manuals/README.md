The manuals use simple English and the names shown on the screens. Each task tells you what to do and what to check afterward. The short checklists at the end can be kept beside the workstation.

Use your own login. If a menu or button is missing, ask the administrator for the access needed for your job.

These instructions cover the version in this repository. Check that the deployed application has the same screens before using the manuals for staff training. Examples explain the steps. They are not instructions to enter sample attendance, pay, purchases or sales into the live system.

Two current application limits affect this work:

- HR can save and print draft payslips. The screens checked here do not provide the final payroll approval and payment controls. The attendance manual explains the handover to the payroll administrator.
- Online sales currently deduct stock from the active factory floor. The invoice form also lists other warehouses. Use the factory floor for the first-sale workflow described here. Ask the administrator before selling stock from another location.
